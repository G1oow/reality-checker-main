# CLI 输出规范

> 目标：让每一个命令的输出**简洁、直观、可预期**。人类看的走一套格式，机器读的保持原样。

## 1. 两条输出通道

| 通道 | 内容 | 规则 |
|---|---|---|
| **stdout** | 机器可读数据：`pipe` 的流式记录、`get/auto --json`、`asn` 的 CIDR 列表、`--export` 写入文件的 JSON | **只放数据**，不放任何提示语；保证 `cmd > file` 结果纯净 |
| **stderr** | 人类可读信息：进度、状态、警告、错误、统计块 | 全部经 `internal/logger` 输出 |

由此保证 `reality-checker-main asn AS15169 US > asn.txt` 得到的文件永远是纯 CIDR 列表。

## 2. 单行格式

```text
[HH:MM:SS] <图标> <短语>：<关键值>
```

- 时间戳：`[HH:MM:SS]`，只出现在运行时信息行，**每行最多一次**（不再出现 `[INFO]`、`[WARN]` 之类重复前缀；级别由图标承担）。
- 图标：只用几何字形，**不用 emoji**（emoji 在中英混排的等宽终端里宽度不稳，会破坏对齐）。
- 短语：2–6 个汉字的名词短语（`扫描完成`、`出口 IPv4`、`命中目标`），后面用全角冒号 `：` 接关键值。
- 关键值：ASCII 术语、数字、单位保留英文原样（`AS24940`、`5 个`、`1m12s`、`443`）。

| 图标 | 常量 | 语义 |
|---|---|---|
| `✔` | `logger.IconOK` | 成功、完成 |
| `›` | `logger.IconStep` | 进行中、步骤开始 |
| `!` | `logger.IconWarn` | 警告、降级、可继续的问题 |
| `✖` | `logger.IconError` | 错误、失败、中止 |
| `·` | `logger.IconDetail` | 细节、数据行（两空格缩进） |

示例：

```text
[14:06:31] › 入口解析：IPv4 <IPv4> 归属 AS24940（DE）
[14:06:33] · 已过滤为 12 个网段，其中 3 个本地库无归属记录
[14:07:45] ✔ 扫描完成：命中 5 个目标（用时 1m12s）
[14:08:02] ! 出口 IPv6：不可用，已自动跳过
[14:08:10] ✖ 查询失败：RIPE Stat 返回 HTTP 500
```

## 3. 输出层 API

所有人类可读信息经 `internal/logger` 产出，禁止在业务代码里 `fmt.Print*` 打提示语。

| API | 用途 | 输出 |
|---|---|---|
| `logger.Info/Step` | 步骤与状态 | `[ts] › ...` |
| `logger.Success` / `Line(logger.IconOK, 短语, 值)` | 成功行 | `[ts] ✔ 短语：值` |
| `logger.Warn` | 警告 | `[ts] ! ...` |
| `logger.Error` | 错误 | `[ts] ✖ ...` |
| `logger.Detail` | 细节行 | `[ts]   · ...` |
| `logger.Linef(icon, 短语, fmt, args...)` | 需要格式化的键值行 | `[ts] <icon> 短语：值` |
| `logger.Block(lines...)` | 无时间戳的对齐块（启动横幅、统计大盘、`--help`） | 原样 |
| `logger.Plain(fmt, args...)` | 表格与结果行 | 原样 |
| `logger.Alignment/DisplayWidth` | 按中英混排显示宽度对齐 | — |

## 4. 定名表（同一语义全局限一个词）

| 语义 | 用词 | 不用 |
|---|---|---|
| 拉取网段后的 IP 存活与 TLS 探测 | **扫描** | 检测、探测、测速 |
| 对已有资产做在线复测 | **复核** | 检查、校验 |
| 查询 ASN / 归属地 / 规则库 | **查询**、**拉取** | 获取、请求 |
| 命中符合条件的伪装目标 | **目标** | 节点、结果 |
| RIPE Stat 返回的 CIDR 集合 | **网段** | 前缀、prefix（代码标识符除外） |

补充：中文与英文术语/数字之间加一个半角空格（如 `已扫描 12,345 个 IP`、`命中 5 个目标`）；括号用全角 `（）`；并列项用 `、`；句末不加句号。

## 5. 帮助与用法

- `--help` / 无参数时的用法块用 `logger.Block` 原样输出，命令与说明列对齐（说明列起始宽度固定）。
- 每个命令一行命令 + 一行说明；参数表里短选项与长选项写在一起（`-l, --limit`）。
- 错误提示只给一条结论 + 必要补充，不打印空行包围的装饰框。

示例（用法块）：

```text
用法:
  reality-checker-main ui        进入 VPS 面板（推荐，快捷指令 rcm）
  reality-checker-main get <ip>  以指定 IP 极速获取伪装目标
```

## 6. 例外（允许直接写 stdout 的数据输出）

以下属于数据通道，不套用上面的格式，改动时**保持逐字节不变**：

- `pipe` 子命令的流式结果行；
- `get/auto` 的 `--json` 输出；
- `asn` 子命令输出的 CIDR 列表；
- `--export` 写出的 JSON 文件内容；
- `report` 包生成的最终结果表格（人类可读，但列对齐与字段顺序属于输出契约，保持结构不变，只允许把流向改为 stderr 之外的零改动）。
