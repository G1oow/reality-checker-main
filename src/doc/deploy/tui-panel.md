# VPS 终端面板（TUI）

> 面板是给 VPS 用的终端界面，不是浏览器页面。安装完成后执行 `rcm` 即可进入。

## 1. 进入与退出

```bash
rcm                  # 进入面板（沿用上次保存的参数）
rcm --help           # 查看全部选项与快捷键
rcm --no-tui         # 不进入全屏界面，直接以纯文本跑一次扫描
```

`rcm` 会按以下顺序定位主程序：`RC_HOME` 环境变量 → 脚本所在目录 → `/root/rc-new` → `~/rc-new` → `/opt/rc` → `/usr/local/rc`。

退出：面板内按 `q`（会先停止正在进行的扫描）。

## 2. 发现来源与校验协议族

扫描分两步：**发现**（扫 IPv4 网段，从站点证书里挖候选域名）与**校验**（按所选协议族验证候选域名）。

| 发现来源 | 触发条件 | 扫描对象 |
|---|---|---|
| **按 VPS 入口 IP ASN** | 默认 | 自动探测本机出口 IPv4/IPv6，取所选入口的 ASN，扫描该 ASN 公告的 **IPv4 网段** |
| **按国家/地区 ASN** | 「扫描模式」选到国家模式 | 在线拉取该国 ASN 清单（RIPE Stat `country-resource-list`），随后逐个 ASN 扫描其 **IPv4 网段** |
| **按 VPS 所在国家 ASN** | 「校验协议族」选「仅 IPv6」时固定使用 | 先用出口探测判定 VPS 所在国家（优先 IPv6 出口，回退 IPv4），再扫该国 ASN 清单的 IPv4 网段；面板里填写国家代码可覆盖自动判定 |

- 入口探测：面板用 `api4.ipify.org` / `api6.ipify.org`（失败回退 `icanhazip.com`）分别探测两个协议族，并在「入口与进度」区显示 `IPv4 <IP> / ASxxxxx / 国家 / 网络类型`；不可用时明确标注（例如 `IPv6 不可用（无 IPv6 出口）`），不会静默跳过。同一 ASN 的 IPv4/IPv6 入口会去重，避免同一批网段被扫两遍。
- **为什么发现阶段只扫 IPv4**：IPv6 聚合大段动辄 2^87 个地址，无法逐 IP 枚举，因此 IPv6 只参与域名校验、不做地址空间扫描；被跳过的 IPv6 网段会带原因显示（`IPv6 网段不参与发现，只做域名校验`）。
- **IPv4 可枚举性**：只扫 `IPv4 ≥ /16` 的网段，更粗的聚合大段会被跳过并说明原因；若某 ASN 完全没有可枚举的 IPv4 网段，面板会直接以 `没有可用的入口 IP：… 聚合段含 2^N 个地址，无法逐 IP 枚举` 失败，而不是静默扫描 0 个 IP。
- **校验协议族**：`仅 IPv4` / `IPv4 + IPv6` / `仅 IPv6`。选「仅 IPv6」时域名必须有 `AAAA` 记录，并用 `tcp6` 完成 TLS 1.3 / HTTP/2 / 证书校验；没有 AAAA 的域名会被剔除，状态栏显示最近一次剔除原因（如 `域名无 AAAA 记录（已限定仅 IPv6 校验）`）。本机没有 IPv6 出口时面板会直接阻止启动并提示改回 IPv4 / 双栈，避免空跑一轮。
- **国家模式**：只接受两位 ISO 代码（如 `DE`、`JP`），清单**只在线拉取、不写入数据库**；ASN 队列按编号升序依次扫描，查询失败或没有可枚举 IPv4 网段的 ASN 会被记录为「跳过」并继续。

## 3. 参数区

| 参数 | 取值 | 说明 |
|---|---|---|
| 扫描模式 | 按 VPS 入口 IP ASN / 按国家/地区 ASN | `←→` 切换；选「仅 IPv6」校验时该行显示为「按 VPS 所在国家 ASN（IPv6 校验固定）」且不再可切换 |
| 校验协议族 | 仅 IPv4 / 仅 IPv6 / IPv4 + IPv6 | 决定域名校验的拨号族；选「仅 IPv6」时发现源自动改为 VPS 所在国家 ASN |
| 国家/地区代码 | 两位 ISO 代码 | 国家模式必填；仅 IPv6 校验时用于覆盖自动判定的 VPS 所在国家（留空=自动） |
| 目标数量 limit | 1 2 3 5 8 10 20 30 50 100 | 命中达到该数量立即停止，上限 100 |
| 扫描并发 | 10 ~ 2000 | 单机 1 核建议不超过 200 |
| 单 IP 超时 | 1 ~ 15 秒 | 死 IP 多时调小可加速熔断 |
| 最低星级 | 不限 ~ 5 星 | 与 `config.yaml` 的 `min_stars` 同义 |
| 握手延迟上限 | 不限 / 100 ~ 2000 ms | 超过即淘汰 |
| 证书剩余天数 | 不限 / 0 ~ 365 天（步进 5） | 剔除临近到期站点 |
| 允许 CDN | 是 / 否 | 默认否，避免 VPS 沦为公网免费反代 |
| 允许热门大站 | 是 / 否 | 默认否，避开 Google/Apple 等超大站 |
| 排除国内站点 | 是 / 否 | 默认是，等价于 `require_no_cn` |
| 排除默认页 | 是 / 否 | 默认是，剔除 Nginx/OpenResty 等默认欢迎页 |

过滤语义与 `config.yaml` 完全一致：面板参数只是**叠加**在配置文件的过滤策略之上（配置文件里的排除域名、后缀、状态码等仍然生效），并且面板扫描**不会写入资产数据库**。

## 4. 快捷键

| 按键 | 作用 |
|---|---|
| `↑` `↓` / `k` `j` | 在参数区（或聚焦结果区后）上下移动 |
| `←` `→` / `h` `l` | 修改当前参数取值（到边界即停） |
| `空格` | 切换当前开关 |
| `回车` | 国家代码行进入输入；其他行等同于向右改值 |
| `tab` | 在「参数区」与「结果区」之间切换焦点 |
| `s` | 一键开始扫描 |
| `x` / `esc` | 停止当前扫描 |
| `r` | 重新探测本机出口 IPv4/IPv6 |
| `q` / `Ctrl+C` | 退出面板（自动停止扫描） |

## 5. 进度与结果

「入口与进度」区实时显示：阶段、进度百分比、已扫描 IP 数、速率（IP/s）、命中数 / limit、候选域名数、当前网段、当前 IP、批次进度、已用时长，以及被跳过的 ASN。

「命中目标」区按星级倒序（同星级按握手延迟升序）展示：域名 / IP / ASN / 国家 / 星级 / 握手延迟 / 证书剩余天数 / 是否 CDN / 状态码。结果**只在本面板展示**，不导出、不入库；需要落库请使用 `auto` / `get` 命令。

## 6. 参数持久化

面板参数在每次修改后立即保存：

- 默认路径：`~/.config/reality-checker/panel.json`
- 覆盖方式：`RCM_SETTINGS=/path/to/panel.json` 或 `rcm --settings /path/to/panel.json`
- 恢复默认：删除该文件即可

命令行的 `--mode` / `--country` / `--family` / `--limit/-m` / `--threads` / `--timeout` 会覆盖本次会话的持久化值，但不会改动其他已保存参数。

## 7. 纯文本模式（脚本 / 无终端环境）

```bash
rcm --no-tui --mode country --country DE --limit 3
rcm --no-tui --family v4 --limit 1
```

纯文本模式复用同一套扫描与过滤逻辑，逐行输出：

```text

[14:06:31] › 国家/地区：DE
[14:06:31] › 目标数量：3（并发 200，超时 3s，校验协议族 IPv4 + IPv6，发现用 IPv4 网段）
[14:06:33] › 国家 ASN 清单：DE 共 812 个 ASN（IPv4 网段 10885 / IPv6 网段 3126，查询时间 2026-01-01T00:00:00）
[14:06:33] › 开始扫描：按国家/地区 ASN 扫描（DE，812 个 ASN）
[14:06:45] ✔ 命中目标：example.com（5 星 / 123 ms / 证书 88 天 / AS24940 / DE）
[14:06:46] ✔ 扫描完成：命中 3 个目标，达到目标数量上限（命中 3 个目标，已扫描 12,345 个 IP，用时 15s）
```

人类可读信息走 stderr，便于脚本只取需要的内容：

```bash
rcm --no-tui --mode country --country JP --limit 1 2>/dev/null   # 只保留数据流场景下用 stdout
```

仅 IPv6 校验（本机有 IPv6 出口）时，发现源自动改为 VPS 所在国家 ASN：

