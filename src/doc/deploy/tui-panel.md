# VPS 终端面板（交互式数字菜单）

> 面板是给 VPS 用的终端界面，不是浏览器页面。安装完成后执行 `rcm` 即可进入。
>
> 面板形态：**交互式数字菜单**（singbox-lite 那类风格）——每轮清屏重绘「状态 + 分组编号菜单」，输入编号进入对应设置或执行动作。不使用备用屏，也不依赖方向键与焦点切换，SSH、手机终端、tmux、Windows Terminal 下操作方式一致。

## 1. 进入与退出

```bash
rcm                  # 进入面板（沿用上次保存的参数）
rcm --help           # 查看全部选项与菜单操作
rcm --no-tui         # 不进入菜单，直接以纯文本跑一次扫描
```

`rcm` 会按以下顺序定位主程序：`RC_HOME` 环境变量 → 脚本所在目录 → `/root/rc-new` → `~/rc-new` → `/opt/rc` → `/usr/local/rc`。

退出：菜单里输入 `0`（扫描参数已自动保存）。

## 2. 发现来源与校验协议族

扫描分两步：**发现**（扫 IPv4 网段，从站点证书里挖候选域名）与**校验**（按所选协议族验证候选域名）。

| 发现来源 | 触发条件 | 扫描对象 |
|---|---|---|
| **按 VPS 入口 IP ASN** | 默认 | 自动探测本机出口 IPv4/IPv6，取所选入口的 ASN，扫描该 ASN 公告的 **IPv4 网段** |
| **按国家/地区 ASN** | 「扫描模式」选到国家模式 | 在线拉取该国 ASN 清单（RIPE Stat `country-resource-list`），随后逐个 ASN 扫描其 **IPv4 网段** |
| **按 VPS 所在国家 ASN** | 「校验协议族」选「仅 IPv6」时固定使用 | 先用出口探测判定 VPS 所在国家（优先 IPv6 出口，回退 IPv4），再扫该国 ASN 清单的 IPv4 网段；菜单里填写国家代码可覆盖自动判定 |

- 入口探测：面板用 `api4.ipify.org` / `api6.ipify.org`（失败回退 `icanhazip.com`）分别探测两个协议族，并在菜单头部的「本机出口」行显示 `IPv4 <IP> / ASxxxxx / 国家 / 网络类型`；不可用时明确标注（例如 `IPv6 不可用（无 IPv6 出口）`），不会静默跳过。同一 ASN 的 IPv4/IPv6 入口会去重，避免同一批网段被扫两遍。
- **为什么发现阶段只扫 IPv4**：IPv6 聚合大段动辄 2^87 个地址，无法逐 IP 枚举，因此 IPv6 只参与域名校验、不做地址空间扫描；被跳过的 IPv6 网段会带原因显示（`IPv6 网段不参与发现，只做域名校验`）。
- **IPv4 可枚举性**：只扫 `IPv4 ≥ /16` 的网段，更粗的聚合大段会被跳过并说明原因；若某 ASN 完全没有可枚举的 IPv4 网段，面板会直接以 `没有可用的入口 IP：… 聚合段含 2^N 个地址，无法逐 IP 枚举` 失败，而不是静默扫描 0 个 IP。
- **校验协议族**：`仅 IPv4` / `IPv4 + IPv6` / `仅 IPv6`。选「仅 IPv6」时域名必须有 `AAAA` 记录，并用 `tcp6` 完成 TLS 1.3 / HTTP/2 / 证书校验；没有 AAAA 的域名会被剔除，扫描结束后「剔除候选」会给出最近一次剔除原因（如 `域名无 AAAA 记录（已限定仅 IPv6 校验）`）。本机没有 IPv6 出口时面板会直接阻止启动并提示改回 IPv4 / 双栈，避免空跑一轮。
- **国家模式**：只接受两位 ISO 代码（如 `DE`、`JP`），清单**只在线拉取、不写入数据库**；ASN 队列每轮随机打乱后依次扫描（编号最小的 ASN 不再固定排在首位，单轮内每个 ASN 只扫一次），查询失败或没有可枚举 IPv4 网段的 ASN 会被记录为「跳过」并继续。

## 3. 菜单项与取值范围

菜单分三块：`扫描参数`（编号 1~6）、`过滤策略`（编号 7~13）、`执行`（`s` / `d` / `r` / `0`）。每项右侧显示当前取值，修改后立即保存。

| 编号 | 菜单项 | 取值 | 说明 |
|---|---|---|---|
| 1 | 扫描模式 | `按 VPS 入口 IP ASN` / `按国家/地区 ASN` | 子菜单选编号；选「仅 IPv6」校验时该项显示为「按 VPS 所在国家 ASN（仅 IPv6 校验固定）」且不可修改 |
| 2 | 校验协议族 | `仅 IPv4` / `仅 IPv6` / `IPv4 + IPv6` | 决定域名校验的拨号族；选「仅 IPv6」时发现源自动改为 VPS 所在国家 ASN |
| 3 | 国家/地区代码 | 两位 ISO 代码 | 国家模式必填；仅 IPv6 校验时用于覆盖自动判定的 VPS 所在国家（回车保留、输入 `-` 清空＝自动） |
| 4 | 目标数量 | 1 ~ 100 | 命中达到该数量立即停止；常用档位 1 / 3 / 5 / 10 / 20 / 50 |
| 5 | 扫描并发 | 10 ~ 2000 | 单机 1 核建议不超过 200 |
| 6 | 单 IP 超时 | 1 ~ 15 秒 | 死 IP 多时调小可加速熔断 |
| 7 | 最低星级 | 0 ~ 5（0＝不限） | 与 `config.yaml` 的 `min_stars` 同义 |
| 8 | 握手延迟上限 | 0 ~ 5000 ms（0＝不限） | 超过即淘汰 |
| 9 | 证书剩余天数 | 0 ~ 3650 天（0＝不限） | 剔除临近到期站点 |
| 10 | 允许 CDN | 是 / 否 | 默认否，避免 VPS 沦为公网免费反代 |
| 11 | 允许热门大站 | 是 / 否 | 默认否，避开 Google/Apple 等超大站 |
| 12 | 排除国内站点 | 是 / 否 | 默认是，等价于 `require_no_cn` |
| 13 | 排除默认页 | 是 / 否 | 默认是，剔除 Nginx/OpenResty 等默认欢迎页 |

过滤语义与 `config.yaml` 完全一致：面板参数只是**叠加**在配置文件的过滤策略之上（配置文件里的排除域名、后缀、状态码等仍然生效），并且面板扫描**不会写入资产数据库**。

## 4. 菜单操作

| 输入 | 作用 |
|---|---|
| `1` ~ `13` | 进入对应设置项的子菜单 |
| 子菜单编号 | 是/否 与枚举类项目直接输入编号；标有「当前」的编号即当前取值 |
| 回车 / `0` / `b` | 保留当前值并返回主菜单（数值输入项用回车或 `b` 返回） |
| 非法输入 | 停留在子菜单并提示合法范围，不会退出面板 |
| `s` | 开始扫描（扫描中按 `Ctrl+C` 只停本次扫描，回到菜单） |
| `d` | 查看上次扫描结果表 |
| `r` | 重新探测本机出口 IPv4/IPv6 与 ASN |
| `0` | 退出面板（扫描参数已自动保存） |

## 5. 进度与结果

扫描开始后，进度以线程安全的日志行实时打印（人类可读信息走 stderr）：阶段、已扫描 IP 数、速率（IP/s）、命中数 / limit、候选域名数、当前网段、当前 IP、批次进度与已用时长。

扫描结束后按 `d` 查看结果表，按星级倒序（同星级按握手延迟升序）展示：域名 / IP / ASN / 国家 / 星级 / 握手延迟 / 证书剩余天数 / 是否 CDN / 状态码。结果**只在面板内展示**，不导出、不入库；需要落库请使用 `auto` / `get` 命令。

## 6. 参数持久化

面板参数在每次修改后立即保存：

- 默认路径：`~/.config/reality-checker/panel.json`
- 覆盖方式：`RCM_SETTINGS=/path/to/panel.json` 或 `rcm --settings /path/to/panel.json`
- 恢复默认：删除该文件即可

命令行的 `--mode` / `--country` / `--family` / `--limit/-m` / `--threads` / `--timeout` 会覆盖本次会话的持久化值，但不会改动其他已保存参数。

## 7. 纯文本模式（脚本 / 无终端环境）

```bash
rcm --no-tui --mode country --country DE --limit 3
rcm --no-tui --family v4 --limit 1
```

纯文本模式复用同一套扫描与过滤逻辑，逐行输出：

```text
[14:06:31] › 发现来源：按国家/地区 ASN
[14:06:31] › 国家/地区：DE
[14:06:31] › 目标数量：3（并发 200，超时 3s，校验协议族 IPv4 + IPv6，发现用 IPv4 网段）
[14:06:33] › 国家 ASN 清单：DE 共 812 个 ASN（IPv4 网段 10885 / IPv6 网段 3126，查询时间 2026-01-01T00:00:00）
[14:06:33] › 开始扫描：按国家/地区 ASN 扫描（DE，812 个 ASN）
[14:06:45] ✔ 命中目标：example.com（5 星 / 123 ms / 证书 88 天 / AS24940 / DE）
[14:06:46] ✔ 扫描完成：命中 3 个目标，达到目标数量上限（命中 3 个目标，已扫描 12,345 个 IP，用时 15s）
```

人类可读信息走 stderr，便于脚本只取需要的内容：

```bash
rcm --no-tui --mode country --country JP --limit 1 2>/dev/null   # 只保留数据流场景下用 stdout
```

仅 IPv6 校验（本机有 IPv6 出口）时，发现源自动改为 VPS 所在国家 ASN：

```text
[14:10:02] › 发现来源：按 VPS 所在国家 ASN（仅 IPv6 校验·发现用 IPv4 网段）
[14:10:02] › 目标数量：1（并发 200，超时 3s，校验协议族 仅 IPv6，发现用 IPv4 网段）
[14:10:02] › 入口候选：IPv6 <IPv6> / AS64500 / DE / 机房，128 个网段
[14:10:02] › IPv6 校验发现源：VPS 所在国家 DE（发现用 IPv4 网段，域名必须有 AAAA 记录）
[14:10:04] › 国家 ASN 清单：DE 共 812 个 ASN（IPv4 网段 10885 / IPv6 网段 3126，查询时间 2026-01-01T00:00:00）

[14:10:40] · 剔除候选：共 2 个（最近：no-aaaa.example — IP解析失败: 域名无 AAAA 记录（已限定仅 IPv6 校验））
```

本机没有 IPv6 出口时，面板不会空跑：直接提示 `本机 IPv6 出口不可用，无法按「仅 IPv6」校验域名；可按 r 重新探测，或改回 IPv4 / 双栈校验`。
